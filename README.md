# É·STORE - Luxury E-Commerce Experience

## About This Project
This was my first solo project assigned to me by my teacher in class when I was first learning web development. It started as a foundational frontend e-commerce website to grasp the core concepts of HTML, CSS, and JavaScript.

Recently, the project has been completely redesigned and elevated into a premium luxury e-commerce experience. The transformation features a modern, elegant, cinematic, and highly responsive UI/UX.

## Tech Stack
- **HTML5**: Semantic structure and accessible layout.
- **Vanilla CSS3**: Custom design system, CSS Grid/Flexbox, dynamic micro-interactions, and a bespoke dark luxury theme. No frameworks like Tailwind or Bootstrap were used.
- **Vanilla JavaScript**: DOM manipulation, dynamic cart state management (using localStorage), and interactivity. No libraries like React or jQuery were used.

## Features
- **Cinematic Hero Section**: High-end visual presentation.
- **Dedicated Product Pages**: Content-rich pages with customer reviews, accordion-based technical specifications, and luxury imagery.
- **State Management**: Functional "Add to Bag" cart logic stored locally.
- **Responsive Design**: Scales beautifully across mobile, tablet, and ultra-wide desktop devices.
